# 《單字地下城與通天塔 Word Dungeon & Babel Tower》PWA

一款結合 **15 大地下城 Boss 討伐戰**、**1000 樓挑戰者通天塔**、**智慧記憶權重抽題 (SRS)**、**持久血量與飢餓情勒互動**，以及 **Supabase 帳號密碼雲端存檔與即時全球競賽排行榜** 的 100% 復古像素風 PWA 背單字 RPG。

---

## 🌟 遊戲特色

1. **雙核心模式**：
   - **地下城討伐戰 (Dungeon Mode)**：15 大固定深度 Boss（B1F 史萊姆王 $\rightarrow$ B15F 終焉時空古龍），耐戰高血量設計，越往下層越難打，單字從學測 7000 單推進至托福與 GRE。
   - **挑戰登塔模式 (Babel Tower Mode)**：1000 樓通天塔試煉，**每答對一題 +1 點積分（滿 5 點升一層樓）**，**每答錯一題 -1 點積分（0 點再錯或 HP 歸零則下降一層）**。遭遇 12 種地牢像素小怪，每 5 層遭遇菁英怪，每 10 層 Boss 色違進化！
2. **100% 復古像素地下城（Zero Emoji Policy）**：
   - 原創像素點陣圖渲染引擎，所有圖示、血條、魔物與紙娃娃換裝（武器/防具/聖物）皆由像素網格手繪而成。
3. **生存與情勒機制**：
   - 受傷不自動回血；多天沒上線每天扣除 15% 最大 HP。天天上線角色熱情誇獎，多天沒上線觸發黑眼圈與毒舌嘲諷情勒！
4. **矮人食堂美食與請假卷**：
   - 5 種平價回血食物 + 5 種時效 Buff 魔法料理（15~30分鐘倒數加成）；5 階公會請假卷（1/3/7/14/30天）免扣血保連勝；神聖回血護樓卷（登塔防降層）。
5. **四大作答題型**：
   - 詞性＋中文雙選、句子克漏字挖空、單字字母挖空拼字、英文情境問答 Q&A，內建 Web Speech API 語音發音。
6. **Supabase 帳號認證與即時全球天梯競賽**：
   - 支援 Email / 密碼註冊登入，進度即時自動同步至雲端，排行榜自動聚合所有真實玩家的最高樓層與連勝天數互相較勁！

## 🚀 快速啟動遊戲

在終端機中切換至專案目錄並啟動本機伺服器：

```bash
cd "/Users/routertt/Documents/Vocabulary Game"
python3 -m http.server 8000
```

打開瀏覽器前往：`http://localhost:8000` 即可開始遊玩！

## ⚡ Supabase 雲端資料庫建置指南（2 分鐘完成）

本遊戲支援離線/訪客遊玩，若要啟用**跨裝置雲端存檔**與**即時全球排行榜競賽**，請依下列步驟設定：

### 步驟 1：建立 Supabase 專案
1. 前往 [Supabase 官網](https://supabase.com/) 登入並建立一個免費專案。

### 步驟 2：執行 SQL 資料表腳本
1. 進入 Supabase 控制台左側選單的 **「SQL Editor」**。
2. 開啟專案內的 `supabase/schema.sql` 檔案，複製全部內容並貼到 SQL Editor 中。
3. 點擊右下角的 **「Run」** 執行，系統將自動為您建置好 `profiles` 資料表、Row Level Security (RLS) 安全策略與使用者自動建立觸發器！

### 步驟 3：在遊戲中綁定 Supabase
1. 進入 Supabase 控制台的 **Project Settings $\rightarrow$ API**。
2. 複製 **Project URL** 與 **Project API Keys (anon public)**。
3. 回到遊戲中，點擊右上角的 **「勇者」頭像** 打開排行榜 $\rightarrow$ 點擊 **「⚙️ Supabase 設定」**。
4. 貼上您的 URL 與 Anon Key 並點擊「儲存連線設定」。
5. 現在切換到「註冊帳號」分頁建立帳號，即可擁有專屬雲端帳號，並在登塔時與所有玩家即時連線比拚排名！
